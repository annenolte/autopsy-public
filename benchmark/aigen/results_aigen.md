# AI-generated code experiment (closes the title gap)

A small Flask app (login, profile photo upload, admin search) was generated by
`claude-sonnet-4-5-20250929` from a **normal feature request** that did NOT ask
for insecure code (`generate_app.py`). The model wrote mostly-secure code —
parameterized SQL, werkzeug password hashing, `secure_filename` on upload — so
the ground truth is deliberately small and conservative: 2 single-line,
AST-detectable, uncontroversial vulns it *did* introduce:

- `aigen-hardcoded-secret-key` — `app.py:9`, hardcoded Flask `secret_key` (CWE-798)
- `aigen-flask-debug-true` — `app.py:63`, `app.run(debug=True)` (CWE-94/CWE-215)

All four tools scored through the frozen matcher (±5 lines), strict + loc-only:

| Tool | recall (strict) | caught |
|------|-----------------|--------|
| **Bandit** (1.9.4) | **100% (2/2)** | hardcoded-secret, flask-debug |
| Autopsy (chunked, Sonnet 4.5) | 50% (1/2) | hardcoded-secret (missed debug) |
| CodeQL (`security-extended`) | 50% (1/2) | flask-debug (missed hardcoded-secret) |
| Semgrep (`p/python`) | 0% (2/2 → 0 strict; 1/2 loc-only) | — (one loc hit, category rejected) |

## Honest reading (reported even though Autopsy does not win)

- **Autopsy detects real vulnerabilities in genuinely AI-generated code** — it
  flagged the hardcoded Flask secret key in code it had never seen, written by a
  model from a benign prompt. That is the existence claim the title needs, and it
  holds.
- **But Autopsy does not dominate on this fixture.** Both labeled vulns are exactly
  Bandit's specialty (single-line config/secret patterns: B201, hardcoded
  secret), so a simple linter scores 2/2 while the LLM scored 1/2. Autopsy and
  CodeQL each caught one and are **complementary** (different one each).
- **Why Autopsy missed `debug=True`:** the windowed LLM treated it as a low-severity
  config note rather than a reported vulnerability; it is a known blind spot for a
  capability-focused scanner versus a rule linter. This is the kind of issue a
  deterministic rule should own (and Bandit does).
- **N=1, 2 labeled vulns** — a small, conservative fixture; not a power comparison.
  The takeaway is qualitative: Autopsy *works on* AI-generated code but is not
  strictly better than off-the-shelf linters on simple config-level bugs.
